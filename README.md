# ワイヤーフレームエスケープ / WIREFRAME ESCAPE

1980年代のグリーンモニターをイメージした、ブラウザで遊べる疑似3D探索型脱出ゲームです。ワイヤーフレームで描かれた屋敷を歩き、鍵を見つけて出口を目指します。

## 遊び方

1. [game.html](game.html) をブラウザで開きます。インストールやビルドは不要です。
2. 画面をクリック・タップするか、キーを押して電源を入れます。
3. 起動演出が終わるとタイトル画面に進みます。途中で画面をタップするかキーを押すと、演出を飛ばして探索を始められます。
4. 鍵を手に入れ、出口の扉を調べるとクリアです。

| 操作 | キーボード | 画面上の操作 |
| --- | --- | --- |
| 前進・後退 | ↑ / W、↓ / S | ▲、▼ |
| 左・右を向く | ← / A、→ / D | ◀、▶ |
| 調べる・決定 | Z / Enter / Space | ACTION |
| 警戒・キャンセル | X / Esc | CANCEL |

画面下部のボタンでミニマップと BGM の表示・再生を切り替えられます。BGM をオフにしても効果音は鳴ります。

## 特徴

- Canvas によるワイヤーフレームの疑似3D描画と CRT 風の画面演出
- Web Audio API で生成する起動音、効果音、探索 BGM、クリア BGM
- クリアタイムの計測とベストタイムの保存
- 隠し通路と探索中に見つかる追加テキスト
- PC のキーボードとタッチ操作に対応

HTML、CSS、JavaScript だけで動作し、外部ライブラリや画像・音声ファイルは使用していません。ベストタイムなどの記録はブラウザの `localStorage` に保存されます。

詳しいゲーム仕様は [documents/readme.md](documents/readme.md) を参照してください。
